# Mindwhisper

Seeded breath meditation — a calm session grown from a single word.

## Live

https://mindwhisper.vercel.app/

- `/` — meditation app (homepage)
- `/tx` — session transmitter (advanced)
- `/rx` — optional sync listener

## Run locally

```bash
cd prototype
npm run build
npm start
```

Open http://localhost:4173
