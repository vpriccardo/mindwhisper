# QR Seal / Hidden envelope / Audio seal — local start / stop

## Start

From the repository root, after a one-time build:

```bash
cd prototype
npm ci
npm run build
cd ..
python3 prototype/server.py
```

Build also regenerates the Hidden-envelope dictionary digest table and carrier
manifest/mask (fails on dictionary collisions or carrier checksum mismatch).

If assets are already built and generated files are current:

```bash
cd prototype && npm run build:skip-prepare && cd ..
python3 prototype/server.py
```

Then open:

- Spectator: http://127.0.0.1:8000/
- Performer: http://127.0.0.1:8001/
- Spectator audio lab: http://127.0.0.1:8000/audio-lab/
- Performer audio lab: http://127.0.0.1:8001/audio-lab/

Hidden-envelope debug overlays: append `?debug=1`.

Optional ports:

```bash
python3 prototype/server.py --spectator-port 8000 --performer-port 8001
```

## Two-tab physical audio test

1. Build and start the dual-origin server.
2. Open performer http://127.0.0.1:8001/audio-lab/
3. Click **Start listening** and grant microphone permission.
4. Verify correct input device and live level.
5. Open spectator http://127.0.0.1:8000/audio-lab/
6. Disconnect Bluetooth/headphones for the first physical test.
7. Set laptop media volume to 60%.
8. Enter `LETTO` (optional fixed salt `42`) and press **Generate and Loop**.
   Playback repeats the 2.1s packet; each cycle starts with the double-chirp
   preamble so the receiver can sync continuously. Use **Stop** when done.
   **Play once** is available for single-shot tests.
9. Verify CRC, exact HENV1 token `2a60a5363d6eb3` (salt 0x2a), and recovered `LETTO`.
10. Mute speaker and prove no acoustic lock occurs (digital loopback off).
11. Test **Repeat same token**.
12. Run **Cover only** and prove it never locks.

There must be no network/storage/BroadcastChannel/SharedWorker/SW/WebSocket/WebRTC
handoff between the tabs — only speaker → microphone.

## Stop

In the terminal where the server is running, press Ctrl+C.

Or from another terminal, kill the default ports:

```bash
lsof -tiTCP:8000 -sTCP:LISTEN | xargs kill
lsof -tiTCP:8001 -sTCP:LISTEN | xargs kill
```

## Spectator offline-after-load

Once http://127.0.0.1:8000/ has fully loaded, the spectator page works with the
browser offline for sealing and rendering (including Hidden envelope assets,
audio seal synthesis, and visible QR/Aztec transports). Offline **refresh** is
not supported (no service worker). Load the page while online first.

Hidden envelope / audio compact tokens are a **dictionary fingerprint, not encryption**.

## Performer camera (including Continuity Camera / iPhone)

Camera acquisition requires a secure context: use `http://127.0.0.1:8001/` or
`http://localhost:8001/`. Permission is requested on **Start camera** (and a
short probe may run when refreshing the device list so labels appear).

Default scan mode is **Audio — primary** (microphone). Use **Hidden envelope —
visual backup** for the camera worker path. Visible QR/Aztec + manual paste live
under **Diagnostics / visible codes**.
